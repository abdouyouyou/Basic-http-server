# Basic-http-server
This is a basic Http server made to test out my HTTP and c sockets understanding.

#Responses
It handles 404, 500 if a file can't open for now, that aswell as the 200 response of course.

#Flow
It waits for requests and then creates a child process to handle the request,once done the child will be handled by a handler to take care of zombies.

##This is a very basic project to test out my understanding of c sockets and the http protocol.
